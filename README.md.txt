# PLP Python Week 4 Assignment

## Files

* `welcome.py`: Uses a welcome function to greet three people.
* `toolbox.py`: Contains functions to double numbers, check passing scores, and greet people.
* `README.md`: Describes the assignment files and reflects on the functions.

## Reflection

The hardest function to write was `greet` because it accepts an optional greeting. I used a default value of `"Hello"` so that the function works when no greeting is provided, while still allowing a different greeting such as `"Habari"`.
